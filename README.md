# Fashion Store

A responsive e-commerce website that provides users with an interactive online shopping experience.

## Features
- Responsive design for desktop and mobile devices
- User registration and authentication
- Product browsing and product details
- Shopping cart and wishlist
- Checkout and order management
- Account management

## Technologies Used
- HTML
- Tailwind CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
